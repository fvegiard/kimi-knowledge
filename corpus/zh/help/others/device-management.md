# 登录设备管理

Kimi 支持同一账号在多端、多设备上登录。通过「登录设备管理」，你可以查看账号当前在哪些设备上登录，并主动移除不再使用或可疑的设备，保障账号安全。

## 在哪里查看？

**网页版（kimi.com）**：点击页面左下角头像 →「设置」→「账号与安全」→「设备管理」。

**App**：「我的」→「设置」→「账号安全」→「登录设备管理」。

![账号与安全设置页中的设备管理入口](https://statics.kimi.ai/kimi-helpcenter-doc/zh-CN/others/images/device-management/entry-settings.fd21ea549b18.png)

## 设备列表说明

设备列表按最近活跃时间倒序排列，每台设备展示以下信息：

- **设备类型图标**：手机 / PC / Web
- **设备名称**：如「iPhone 16 Pro Max」「MacBook Pro」；无法识别型号时展示系统原始字符串
- **登录地点**：基于登录时 IP 解析的城市名称，解析失败时显示「未知」
- **最近活跃时间**：本机设备固定显示「刚刚」，其他设备显示精确时间

此外：

- 本机设备置顶展示，设备名称后带「本机设备」角标
- 列表仅展示 1 年内活跃的设备，超过 1 年未活跃的设备不再展示

![登录设备管理列表弹窗](https://statics.kimi.ai/kimi-helpcenter-doc/zh-CN/others/images/device-management/device-list.012703fbb2eb.png)

## 如何移除设备？

1.  在设备列表中，点击待移除设备右侧的「移除」。
2.  在确认弹窗中再次点击「移除」，该设备上的 Kimi 账号将被登出。

如发现可疑设备，请及时移除并修改账号密码。当列表中非本机设备超过 3 台时，页面底部会出现「一键移除」，可一次性移除全部非本机设备（本机设备不受影响）。
