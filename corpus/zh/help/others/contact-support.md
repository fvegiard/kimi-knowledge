# 如何联系 Kimi 客服？

根据你的问题类型，选择下面对应的渠道，能更快获得帮助。

## 人工客服（企业微信）

关注微信公众号「**月之暗面Kimi**」，在底部菜单点击「**联系我们**」→「**联系客服**」，即可找到官方企业微信人工客服。

## 邮箱支持

| 问题类型                                                             | 邮箱                                                                                              |
|----------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| **付费会员问题**（权益未到账、支付扣款异常、升降级、发票等）         | [\[email protected\]](/cdn-cgi/l/email-protection#1a777f77787f686972736a5a777575746972756e347974) |
| **一般问题**（产品功能咨询、使用技术问题、非付费账号问题、功能建议） | [\[email protected\]](/cdn-cgi/l/email-protection#b7c4c2c7c7d8c5c3f7dad8d8d9c4dfd8c399d4d9)       |
| **账号申诉 / 投诉举报**                                              | [\[email protected\]](/cdn-cgi/l/email-protection#dfacaaafafb0adab9fb2b0b0b1acb7b0abf1bcb1)       |
| **Kimi API 开发者支持**                                              | 登录 [Kimi 开放平台](https://platform.kimi.com/) 查询客服联系方式与开发者社群                     |

发邮件时请附上你的账号信息（注册手机号或邮箱）和问题截图，付费会员的邮件将获得优先处理，我们能更快定位问题。

## 产品内反馈

你也可以直接在 Kimi 产品内提交反馈，系统会自动附带设备与账号信息，便于我们排查：

- **网页版**：点击左下角「账号 → 用户反馈 → 帮助与反馈」。
- **手机 App**：进入「账号 → 设置 → 意见反馈」。

## 对话质量反馈

如果对某次回答不满意，可在该条回复下点击「👎」，简要说明问题类型与具体偏差，帮助我们持续优化。

会员相关问题也可查看[会员问题联系方式](/help/membership/membership-contact)。媒体联络请发送邮件至 [\[email protected\]](/cdn-cgi/l/email-protection#95e5e7d5fefcf8fcbbf6faf8)。
