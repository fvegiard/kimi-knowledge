# Kimi会员自助开票

Kimi 支持用户自助开具电子发票，操作简单便捷。你可以直接访问[会员订阅页面](/membership/subscription)进入开票流程。

## 开票操作步骤

![开票操作页面](https://statics.kimi.ai/kimi-helpcenter-doc/zh-CN/membership/images/membership/invoice-01.f13c0c91301b.gif)

1.  登录 Kimi，进入「设置 → 管理 → 订阅」页面。
2.  找到需要开票的订单，点击「开发票」。
3.  选择发票类型并填写开票信息。
4.  确认信息无误后提交申请。
5.  发票将以电子版形式发送到你填写的邮箱。

## 支持的发票类型

| 发票类型       | 说明                                                           |
|----------------|----------------------------------------------------------------|
| 普通个人发票   | 抬头为个人姓名，无需税号                                       |
| 普通企业发票   | 需填写企业名称和纳税人识别号                                   |
| 增值税专用发票 | 需填写企业完整开票信息（名称、税号、地址、电话、开户行及账号） |

## 注意事项

- 电子发票与纸质发票具有同等法律效力。
- 发票金额为实际支付金额（不含优惠券等抵扣部分）。
- 发票通常在提交申请后 1-3 个工作日内开具完成。

## 已开票如何重新发送？

如果发票邮件丢失或需要发送到其他邮箱：

1.  进入「设置 → 管理 → 订阅」页面。
2.  找到已开票的订单，点击「查看发票」或「重新发送」。
3.  输入新的接收邮箱地址，确认发送即可。
