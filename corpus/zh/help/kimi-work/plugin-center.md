# 插件中心

Kimi Work 插件中心汇集了 Kimi 官方提供的专业数据库插件和精选外部应用插件，帮助你在对话中快速获取专业信息、操作常用工具，或扩展 Kimi 的任务能力。

除使用插件中心提供的插件外，你也可以在 Kimi Work 中创建和测试个人自定义插件，接入更多符合自身工作需求的工具和服务。

## 内置专业数据库插件

Kimi Work 内置金融、法律、学术等领域的专业数据库插件，为专业人士提供专业、可信的数据来源，覆盖国内与全球数据源：

- **金融数据**：Wind 万得金融数据服务、恒生聚源金融数据、标普全球市场财智、全球金融数据库、IMF 国际货币基金组织数据库、同花顺等
- **工商 / 法律**：天眼查、华宇元典等

## 精选外部应用插件

插件中心提供官方精选的外部应用插件，包括：

- **办公协作类**：百度网盘、钉钉、飞书、WPS
- **设计类**：Canva 可画
- **笔记类**：Notion
- **网站开发类**：Cloudflare
- **其他**：Kimi Computer Use（AI 控制桌面进行系统级操作）、GitHub、Neon（云端 PostgreSQL 数据库平台）、Supabase（开源后端与数据库平台）等

安装插件后，Kimi Work 可以直接调用相关应用和服务。你只需用一句话描述任务，Kimi 就能根据需求选择合适的插件，减少重复操作，提升工作效率。

## 插件启用方式

1.  打开最新版 Kimi 电脑客户端，在左侧边栏切换至「Work」模式，点击「插件」进入插件中心；
2.  在「已安装」或「精选插件」中找到需要使用的插件并安装；
3.  在对话框输入斜杠「/」，选择要调用的插件即可使用。

## 在 Kimi Work 中自定义插件

除了使用插件中心中的官方插件，你还可以通过 Plugin Builder 在 Kimi Work 中创建个人自定义插件，将自己的工作流程、专业知识或外部服务接入 Kimi。

创建完成后，可以在「插件」→「个人」中安装插件，并在新会话中通过斜杠「/」唤起和测试。

具体创建步骤和使用说明，请参考[如何创建个人插件](/help/plugins-and-skills/create)。
