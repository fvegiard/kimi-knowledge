# Kimi Work 常见问题

## Kimi Work 和网页版有什么区别？

Kimi 网页版适合快速对话和查询；Kimi Work 是为深度工作流设计的本地 Agent。它能读取并处理你的本地文件夹、通过 WebBridge 自主浏览网页、在后台运行 Python 代码、执行定时任务，是一个系统级的「数字员工」。

## 访问本地文件时，Kimi Work 如何保护我的隐私？

你对自己的文件拥有绝对控制权。Kimi Work 提供三档权限控制，由你自行选择授权方式：

- **默认**：常规操作自动执行，Kimi 在修改、覆盖本地文件或运行代码等敏感操作前会请求你的明确授权；
- **手动允许**：操作前先请求授权；
- **全部**：无需授权直接执行。

选择「手动允许」时，未经你同意不会发生任何操作。

开启「全部」（全自动）权限后，AI 将直接读写文件、执行代码、修改系统配置，也会自动处理原本需要你决定的步骤。这可能会产生：

- 文件被覆盖、误删或损坏；
- 系统配置被更改，导致软件异常；
- 磁盘加密、分区或固件变更，导致设备受限或无法启动等问题。

部分操作不可逆，数据可能永久丢失且无法恢复。请知悉该模式的风险，谨慎使用并做好数据备份。

开启「全部」（全自动）权限即视为你知悉并接受上述风险，并授权 AI 自主执行相关操作，基于你的授权所执行操作的结果将由你自行承担。

## WebBridge（浏览器自动化）具体能做什么？

WebBridge 让 Kimi 能像人一样使用浏览器。你可以让它查看某个网站的最新资讯并总结，或把历史股票数据抓取到本地 Excel。它会自主点击、滚动、提取数据，为你节省大量手动操作时间。

## 定时任务能做什么？电脑休眠时还会运行吗？

定时任务让 Kimi 到设定的时间自动执行一段固定的任务，支持每天、每周、每月与永不重复（单次），适合每日简报、每周监控、定期整理等重复性工作。

在 Kimi Work 桌面端，定时任务在**本地运行**，需要**应用处于开启状态**才会执行；电脑休眠、关机或应用关闭期间错过的触发**不会在下次开启时补跑**。因此如需任务在夜间执行，请保持电脑与 Kimi Work 应用处于开启运行状态。（相比之下，在 Kimi 中创建的定时任务在云端执行，不需要保持客户端开启。）

更多说明见[定时任务](/help/features/scheduled-tasks)。
