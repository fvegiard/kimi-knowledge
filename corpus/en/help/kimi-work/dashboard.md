# Dashboard

A dashboard is a container for widgets. It brings the widgets you care about most into one persistent, personalized view, organized around a topic, project, or goal. A dashboard is not tied to any single conversation — you can open it at any time, and manage its widgets from any chat.

## Creating and Managing Dashboards

1.  Click "Dashboard" in the left sidebar to open the Dashboard menu;
2.  Click "Create" and fill in a name (required) and a description (optional);
3.  Each user can create up to 2 dashboards.

On an empty dashboard, you can directly describe the widget you want, and Kimi will build it into that dashboard.

Deleting a dashboard also deletes all widgets in it and their associated widget tasks. This cannot be undone — please proceed with caution.

## Layout and Annotations

- Each dashboard can hold up to 20 widgets. Drag to rearrange them and resize them as you like.
- Click "Refresh" to update the content of the widgets on the dashboard.
- Click "Annotate" to enter annotation mode: select any element in a widget to create a positional annotation and record your feedback. Annotations are listed in chronological order, up to 10 entries; click a saved annotation to edit it again.

## Managing Widgets on a Dashboard

Hover over a widget to:

- Click "Expand" to view the widget's name and type;
- For a live widget, manage its bound widget task: view the task name and description, toggle it on or off, and check the 10 most recent runs (run time and status);
- Click "…" to choose:
  - **Delete**: permanently removes the widget from the original chat and all dashboards — this cannot be undone;
  - **Pin to Desktop**: pins the widget to your computer desktop as a standalone window with a customizable size; the window closes automatically when you quit the app.

## Opening a Dashboard from a Chat

The model can surface a dashboard card in a chat. Click the card to open the corresponding dashboard page in the right-side panel, without leaving the current conversation.
