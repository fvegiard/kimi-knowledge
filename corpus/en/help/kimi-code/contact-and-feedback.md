# Contact & Feedback

## Feedback channels

If you run into any issues while using Kimi Code or have suggestions, you can share feedback through the following channels.

### Option 1: Send feedback directly in the CLI

In the interactive mode of Kimi Code CLI, enter the `/feedback` command to submit feedback. The system will automatically collect information about your current environment, helping you describe the issue more accurately.

### Option 2: GitHub Issues

Visit [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) and search to see whether a similar issue already exists. If not, you can create a new Issue and describe what you encountered in detail.

### Option 3: Email feedback

You can also email the Kimi Code team at [\[email protected\]](/cdn-cgi/l/email-protection#abc8c4cfceebc6c4c4c5d8c3c4df85cac2) to report issues. Please include as much of the following information as possible:

- **Issue description**: Clearly describe the issue you encountered or the feature you would like
- **Steps to reproduce**: How to trigger the issue step by step
- **Environment information**: Operating system and Kimi Code CLI version (run `kimi --version` to check)
- **Error logs**: If there is an error message, please paste it in full

### Option 4: Join the Feishu group

Scan the QR code to join the Feishu group

![Feishu group QR code](https://statics.kimi.ai/kimi-helpcenter-doc/en-CN/kimi-code/images/contact-and-feedback/contact-and-feedback-01.d734809b11ed.png)

## Troubleshooting before submitting feedback

Before submitting feedback, we recommend checking the following:

- Whether you have updated to the latest version of Kimi Code CLI (run `kimi --version` to check)
- Whether your network connection is working and whether you can access `api.kimi.com`
- Whether your API Key is valid and has not expired
- Whether the working directory is correct and Kimi has permission to access the relevant files
