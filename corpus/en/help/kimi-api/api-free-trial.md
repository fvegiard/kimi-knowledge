# Free Trial Benefits

Kimi API provides newly registered users with free trial credit, so you can fully experience the platform before you start using it formally.

## Voucher Grant Rules

- **Eligible users**: New users who register with a mainland China mobile number.
- **Voucher amount**: An **RMB 15 voucher** is granted upon registration.
- **Validity period**: The voucher is valid for **3 months** from the date it is issued and expires automatically afterward.

## How the Voucher Works

- The voucher is applied automatically to API usage; no manual activation is required.
- The voucher balance is deducted before your top-up balance.
- You can view your remaining voucher credit on the “Cost Details” page in the console.

## What can you do with RMB 15?

An RMB 15 voucher is enough for extensive development testing, such as:

- Hundreds of standard chat requests
- Dozens of long-document parsing runs
- Sufficient API integration debugging and feature validation

The exact number of uses depends on the model you choose and the amount of token consumed by each request.

## After the Voucher Is Used Up

After the voucher is used up, API calls will be charged against your top-up balance. If your balance is zero, API requests will return a 403 error. You can top up in the console at any time; funds are available immediately after top-up.
