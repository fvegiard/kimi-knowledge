# Kimi API Introduction

The Kimi API Open Platform gives developers access to powerful LLM capabilities, helping you quickly integrate AI into your own products and services.

## Platform Overview

Kimi API is built on Moonshot’s in-house LLM and provides core capabilities such as text generation, multi-turn conversations, file parsing, and web search. The platform is compatible with the OpenAI API format, making migration and integration cost-effective for developers.

**Platform URL**: [platform.kimi.com](https://platform.kimi.com/)

## Who It’s For

- **Independent developers**: Quickly build AI-powered personal projects or tools.
- **Enterprise engineering teams**: Embed AI capabilities into enterprise products to improve user experience and business efficiency.
- **Startups**: Access leading AI capabilities at low cost and accelerate product iteration.

## Key Use Cases

- **Intelligent customer service**: Automated Q&A based on contextual understanding to improve service efficiency and user satisfaction.
- **Content generation**: Creative tasks such as article writing, marketing copy, and code generation.
- **Data analysis**: Document interpretation, report analysis, knowledge extraction, and summarization.
- **Knowledge Q&A**: Intelligent retrieval and Q&A systems built on private document libraries.

## Quick Start

1.  Visit [platform.kimi.com](https://platform.kimi.com/) to register a developer account.
2.  Create an API Key in the console.
3.  Follow the API documentation to make your first call.
4.  Choose the appropriate model and parameters based on your business needs.
