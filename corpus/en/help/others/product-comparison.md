# What are the differences between Kimi, Kimi Work, Kimi Code, and Kimi Claw? Which one should I use?

Kimi includes both a ready-to-use online assistant and several products designed for different users and scenarios. They share Kimi’s core capabilities, with the main differences being **where you use them, who they are for, and what they do best**.

## Differences at a glance

| Product              | What it is                                                       | Best for                                                                                                           | Where to use it            |
|----------------------|------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------|----------------------------|
| **Kimi** (web / App) | An online AI assistant that combines chat and Agent capabilities | Everyday Q&A, writing, search, website / PPT / document and spreadsheet creation, Deep Research, and more          | Web and mobile App         |
| **Kimi Work**        | A **local Agent** for knowledge workers (desktop)                | Working with local files on your computer, automating tasks across desktop apps, and completing long-running tasks | Mac / Windows client       |
| **Kimi Code**        | A coding assistant suite for **developers**                      | Writing code and maintaining codebases                                                                             | CLI and VS Code extension  |
| **Kimi Claw**        | A **zero-deployment cloud automation** platform                  | 24/7 cloud automation and bots connected to Feishu / WeChat and other platforms                                    | Cloud (no server required) |

## Which one should I use?

- **For everyday chat, writing, search, or asking Kimi to build a website, create PPTs and spreadsheets, or conduct Deep Research** → Use **Kimi** (web / App).
- **If you need Kimi to read and write local files on your computer, automate workflows across multiple desktop apps, or run long tasks** → Use **Kimi Work** (desktop).
- **If you are a developer and mainly need help writing code or maintaining projects** → Use **Kimi Code**.
- **If you want a cloud-based bot that stays online, runs automatically, and connects to Feishu / WeChat and other platforms** → Use **Kimi Claw**.

Kimi’s online experience already combines “chat” and “Agent”, so you do not need to switch between them. In the Kimi Work desktop client, there are two modes: “Work” (an Agent mode for deliverables) and “Chat” (for quick conversations).

## Which membership plan should I choose?

Membership benefits are tied to your Kimi account. All membership features (chat, Agent, Deep Research, Kimi Code, and more) **share the same credit pool**. Kimi Code also has a separate limit of 5 hours per week, which applies only to Kimi Code. For plan details and pricing, see the [membership subscription page](/en/help/membership/membership-pricing).

If you mainly use Kimi for **daily needs plus occasional tasks**, a suitable Kimi membership plan will cover most scenarios across web / App / Kimi Work. Developers who **code frequently** may also want to review the Kimi Code benefits.
